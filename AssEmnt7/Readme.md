# Assignment 7 – File Handling in C#

### 1. Write Line
- Creates a new file named `this file.doc`.
- Writes four lines of text into the file.
- Displays a success message after writing.

### 2. Delete File
- Checks whether the file exists.
- Deletes the file if it exists.
- Clears the ListBox.
- Displays a confirmation message.

### 3. Read All Lines
- Reads all lines from the file using `File.ReadAllLines()`.
- Displays all lines in the ListBox.

### 4. Read Line
- Reads the file line by line using `File.ReadLines()`.
- Displays the lines in the ListBox.

### 5. Delete Item
- Clears all items from the ListBox.

## Conclusion
This project helps students understand basic file handling operations in C#, including creating, writing, reading, and deleting files.
