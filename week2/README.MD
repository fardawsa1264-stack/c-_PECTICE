///First Image – Clear Button
The first image explains the Clear button in a C# Windows Forms application. The Clear button is used to remove or reset the information entered by the user. When the user clicks the Clear button, the program uses the Clear() method to remove the text from different text boxes. It clears the information from the input fields such as day, month, and year. It also clears the output label by using string.Empty. This means that all the information entered on the form will be removed, and the form will become empty again. The Clear button is useful when the user wants to enter new information or start again.

Second Image – Show Info Button
The second image explains the Show Info button in a C# Windows Forms application. The Show Info button is used to collect information from different text boxes and display it as output. First, the program creates variables such as name, department, semester, and id. Then, it gets the information from the text boxes using the .Text property. The ID is converted from text into a number using int.Parse(). After collecting all the information, the program combines the values into one string called fulldata. Finally, the complete information is displayed in the output label. This allows the user to see all the information entered in one place.
